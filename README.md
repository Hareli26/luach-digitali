# לוח דיגיטלי לבית הכנסת · Digital Synagogue Board

לוח דיגיטלי מודרני לבית כנסת — זמני היום לפי מיקום GPS מדויק, זמני תפילות, פרשת השבוע, דף יומי,
כיוון לירושלים, ומאגר דברי תורה קצרים (תהילים, משלי, פרקי אבות, הלכה, רמב״ם, רבי נחמן מברסלב, מוסר).

מיועד להצגה על מסך גדול / טלוויזיה בבית הכנסת, עם סבב מסכים אוטומטי ולוח בקרה (גבאי) להגדרות.

## תכונות

- **זמני היום** — חישוב מדויק עם `kosher-zmanim` (KosherJava) לפי קו רוחב/אורך/גובה ואזור זמן.
  עלות השחר, טלית ותפילין, הנץ, סו״ז ק״ש (מג״א/גר״א), סו״ז תפילה, חצות, מנחה גדולה/קטנה,
  פלג המנחה, שקיעה, צאת הכוכבים (גאונים / 8.5° / ר״ת). הזמן הקרוב מודגש.
- **זמני תפילות** — שחרית / מנחה / ערבית / שיעורים. זמן קבוע (`06:30`) או יחסי לזמני היום
  (`sunset-18`, `tzeit+0`, `sunrise+0`, `plag+0`). הגדרה לפי ימים (חול / שבת / כל יום).
- **תאריך עברי** — תאריך מנוקד, יום בשבוע, פרשת השבוע, דף יומי, ראש חודש, ספירת העומר, יום טוב.
- **כיוון לירושלים** — מצפן עם חישוב זווית מעגל גדול להר הבית + מרחק בק״מ; מתכייל אוטומטית
  לחיישן המכשיר (deviceorientation) במסכי מגע.
- **לימוד יומי** — דף יומי בבלי, דף יומי ירושלמי, פרשת השבוע, ודבר תורה יומי.
- **זמני השבוע** — טבלת 7 ימים (הנץ / חצות / שקיעה / צאת), היום מודגש.
- **הזכרת נשמות (יארצייט)** — זיהוי אוטומטי לפי תאריך עברי: "נר נשמה היום" + רשימת יארצייט קרוב (עד 45 יום).
- **ספירת העומר** — מסך ספירה גדול (מופיע אוטומטית רק בימי הספירה) עם ספירת המידות.
- **מאגר דברי תורה** — טקסטים קצרים מנוקדים עם מקור, מתחלפים בסבב. קטגוריות: חומש, תהילים, משלי,
  פרקי אבות, משנה, גמרא, הלכה, רמב״ם, רבי נחמן מברסלב, מוסר. ניתנות לבחירה.
- **הודעות קהילה** — מסך הודעות + כיתוב רץ (ticker) בתחתית.
- **ספירה לאחור** — לתפילה הבאה של היום.
- **נוסח** — אשכנז / ספרד / עדות המזרח / תימן / חב״ד.
- **מסך מלא (Kiosk)** — כפתור ⛶ או מקש `F`.
- **עיצוב** — שלושה מצבי תצוגה: כהה / קלף / בהיר. RTL מלא, טיפוגרפיה עברית גדולה, רספונסיבי (מותאם 16:9).

## התקנה בכמה מחשבים (MSI)

```bash
npm run msi      # בונה release/LuachDigitali-1.0.0-x64.msi (דורש WiX Toolset 5)
```

ה־MSI מתקין את הלוח לכל המשתמשים (Program Files), מוסיף קיצור בתפריט התחל ועל שולחן העבודה,
ומפעיל את הלוח **אוטומטית עם עליית Windows** לכל משתמש שנכנס, במסך מלא (קיוסק).

**פריסה שקטה בכמה מחשבים:** מעתיקים לתיקייה אחת (דיסק און קי או תיקייה ברשת) את ה־MSI, את `deploy.cmd`,
ואם רוצים גם `settings.json` (קובץ גיבוי שהורד מהלוח: הגדרות ← תצוגה וגיבוי). בכל מחשב מריצים את `deploy.cmd` כמנהל.
אפשר גם ישירות: `msiexec /i LuachDigitali-1.0.0-x64.msi /qn AUTOSTART=1 DESKTOPSHORTCUT=1`.

**הגדרות אחידות לכל המחשבים:** קובץ `C:\ProgramData\LuachDigitali\settings.json` נטען בהפעלה
בכל פעם שהוא חדש יותר מהקובץ שהוחל במחשב בפעם הקודמת. כדי לעדכן את כל הלוחות, מחליפים את הקובץ.

**הקיוסק:** אי אפשר לסגור את הלוח ב־Alt+F4. אם הדף קורס הוא נטען מחדש מעצמו, ובכל לילה ב־03:00 הוא מתרענן.
רק לוח אחד יכול לרוץ בכל מחשב. יציאה: `Ctrl+Shift+Q` · מעבר בין קיוסק לחלון רגיל: `F11`.

> כדי שהלוח יעלה בלי שמישהו יקליד סיסמה, צריך להגדיר ב־Windows כניסה אוטומטית למשתמש של הלוח
> (למשל עם הכלי Autologon של Microsoft Sysinternals). אפשר גם להשבית שינה ושומר מסך, אבל הלוח בכל מקרה מונע כיבוי מסך כל עוד הוא פועל.

## אפליקציית קיוסק (Electron)

להרצה כאפליקציית שולחן עבודה במסך מלא (ללא דפדפן), שמונעת כיבוי/עמעום מסך —
אידיאלי לטלוויזיה קבועה בבית הכנסת.

הרצה בפיתוח (צריך שהשרת `npm run dev` ירוץ במקביל):

```bash
npm run electron:dev
```

אריזה למתקין Windows (מתקין + גרסה ניידת) — התוצר ב-`release/`:

```bash
npm run electron:build
```

התוצרים:
- `release/Luach Digitali Setup 1.0.0.exe` — מתקין (NSIS), מאפשר בחירת תיקייה וקיצור שולחן.
- `release/Luach Digitali 1.0.0.exe` — גרסה ניידת (exe בודד, ללא התקנה).
- `release/win-unpacked/` — תיקייה ניידת מלאה (אפשר להעתיק ולהריץ את ה-exe).

> **אם הבנייה נכשלת עם** `Cannot create symbolic link ... winCodeSign`: זו מגבלת הרשאות של Windows
> ליצירת symlink. פתרונות: (א) הפעלת **Developer Mode** (הגדרות → למפתחים) ואז `npm run electron:build`;
> או (ב) הרצה מחלון מנהל; או (ג) חילוץ מראש של ה-cache ללא תיקיית darwin:
> ```bash
> "node_modules/7zip-bin/win/x64/7za.exe" x \
>   "$LOCALAPPDATA/electron-builder/Cache/winCodeSign/<id>.7z" \
>   -o"$LOCALAPPDATA/electron-builder/Cache/winCodeSign/winCodeSign-2.6.0" -xr!darwin -y
> ```
> ואז להריץ שוב `npm run electron:build` (electron-builder ידלג על החילוץ הכושל).

קיצורים בקיוסק: `Ctrl+Shift+Q` ליציאה · `F11` מעבר מסך מלא · `S` הגדרות.

> הערה: במצב קיוסק (Electron) איתור GPS וחיישן המצפן אינם זמינים (אין חיישנים במחשב שולחני) —
> יש להזין את המיקום ידנית או לבחור עיר מההגדרות. שאר הזמנים מחושבים רגיל מקו הרוחב/אורך.

## מסכים (28) וקיצורי מקשים

כל מסך נפתח ישירות במקש משלו (לפי המקש הפיזי, עובד גם במקלדת בעברית). `H` מציג את רשימת הקיצורים.

| מקש | מסך | | מקש | מסך |
|---|---|---|---|---|
| `1` | ענייני השבוע: פרשה, הפטרה, שבת, פרקי אבות, מברכים | | `Q` | מבט אחד: זמנים, תפילות, הודעה, יארצייט |
| `2` | זמני תפילות: היום + שבת הקרובה | | `W` | זמני השבוע |
| `3` | ענייני דיומא: גבורות, ברכת השנים, יעלה ויבוא, על הניסים, הלל, תחנון, צדקתך, עננו | | `E` | תורמים |
| `4` | הודעות ואירועים (מזל טוב, ברית, שבת חתן…) | | `R` | הקדשת הלוח |
| `5` | זמני היום | | `T` | ימי הולדת (בשבוע שיש) |
| `6` | הלכה יומית (קיצור שו״ע או הלכות משלכם) | | `Y` | תפילות חג (לפני חג שהוגדר) |
| `7` | הזכרת נשמות: היום, השבוע, החודש, שנת האבל | | `U` | ספירת העומר (בימי הספירה) |
| `8` | תמונות | | `I` | לימוד יומי (דף יומי, משנה, רמב״ם, נ״ך, חפץ חיים…) |
| `9` | משנה יומית (טקסט מלא) | | `O` | דבר תורה |
| `0` | לוח שיעורים | | `P` | חנוכה: מנורה, ברכות, זמן הדלקה |
| | | | `A` | זמני צום (מ־3 ימים לפני) |
| `N` | עצה מרבי נחמן: ליקוטי עצות, ספר המידות, שיחות הר״ן | | `J` | כיוון לירושלים |
| `K` | הלכה בעיתה: הלכות שמתאימות לשבוע (שבת, חג, ראש חודש, בין המצרים) | | `D` | קשת היום: מסלול השמש וכל הזמנים בקשת אחת |
| `M` | מה לפנינו: ספירה לאחור לשבת וציר זמן של 45 יום | | `L` | קידוש לבנה (בזמנו) |
| `Z` | לרפואה שלמה | | | |

**דברי תורה מתחלפים כל שני סבבים** (לא בכל הופעה), ומתחילים כל יום ממקום אחר.

**מאגר טקסטים מקורי** (`src/data/bank`, נבנה מספריא ע״י `node scripts/build-bank.mjs`): כ־580 עצות מליקוטי עצות, כ־2,200 מספר המידות, שיחות הר״ן, קיצור שולחן ערוך מלא, שולחן ערוך אורח חיים, מסילת ישרים ופרקי אבות. כל קטע מובא מילה במילה, עם המקור המדויק. הקבצים נטענים רק כשמסך צריך אותם.

**עשרה רקעים מעוצבים** (שמי לילה, אבן ירושלמית, קשתות, רימונים, מגן דוד, טלית, גפן, גלים, מסגרת): אפשר לבחור רקע לכל מסך ולכל הודעה, והם נצבעים לפי ערכת הצבעים.

מסכים עונתיים או ריקים (עומר, חנוכה, צום, תפילות חג, ימי הולדת, תורמים, תמונות) נכנסים לסבב רק כשיש להם תוכן.

| מקש / פעולה | תוצאה |
|---|---|
| `←` / `→` | מעבר בין מסכים |
| רווח | השהיה / המשך הסבב |
| `F` | מסך מלא |
| `S` | הגדרות |
| `H` | קיצורי מסכים |

## הגדרות (לוח גבאי)

- **מיקום**: שם בית הכנסת, יישוב, קו רוחב, קו אורך, גובה, GPS, ערים, אזור זמן, מנהג ארץ ישראל.
- **זמנים ונוסח**: נוסח, הדלקת נרות, הבדלה, שיטת צאת הכוכבים.
- **תפילות**: שעה קבועה, שעה יחסית (`sunset-18`) או הערה בלי שעה (״לאחר מנחה״). לכל תפילה בוחרים ימים (כולל ימים נבחרים בשבוע) ומשך. **היסח הדעת**: בזמן התפילה הלוח נשאר על מסך אחד לבחירתכם.
- **תפילות חגים**: זמנים לכל חג. המסך מופיע מספר ימים שתבחרו לפני החג.
- **שיעורים**: נושא, מוסר השיעור, שעה וימים. השיעורים של היום מודגשים.
- **נשמות וימי הולדת**: תאריך עברי ושנת פטירה (לא חובה, כדי להציג את מי שבתוך שנת האבל).
- **הודעות**: סוג (רגילה או אירוע) ותזמון: תמיד, ימים בשבוע, מתאריך עד תאריך, לפני חג, או בשבוע של פרשה.
- **תורמים והקדשה**: תורמים מרכזיים מקבלים מסך שלם. ההקדשה יכולה לרוץ גם ברצועה התחתונה.
- **לימוד ותמונות**: בחירת מחזורי הלימוד, הורדת הנוסח המלא מספריא (נשמר לשימוש בלי רשת), הלכות משלכם, העלאת תמונות.
- **מסכים וזמנים**: הפעלה וכיבוי של כל מסך, שניות לכל מסך בנפרד לחול, לשבת ולחג, והעתקת זמני חול לשבת ולחג. בנוסף: רצועת זמנים תחתונה, ושעות פעילות (הלוח מוחשך בשעות שבית הכנסת סגור, ובשבת ובחג נשאר דולק).
- **תצוגה וגיבוי**: ערכת צבעים, הורדת קובץ גיבוי וטעינה ממנו (להעברה למחשב אחר), איפוס.

ההגדרות נשמרות ב־`localStorage`, והתמונות ב־IndexedDB.

## הערות הלכתיות

החישובים מבוססים `kosher-zmanim` (יציאת KosherJava). יש לוודא מול לוח מקומי / רב מורה הוראה
לפני שימוש למעשה, במיוחד לגבי שיטת צאת הכוכבים והיסטי הדלקת נרות/הבדלה בכל יישוב.
